# js-calc
A simple calculator built with HTML, CSS and JavaScript as part of The Odin Project.

It handles basic operations like adding, subtracting, multiplying and dividing. You can chain operations, so something like 12 + 7 - 1 works the way you'd expect. Long decimals get rounded so they fit on the display, and dividing by zero won't break anything (but the calculator will let you know what it thinks about it).

To try it out, just open index.html in your browser.
